# aviation_dataengineering_project
# ✈️ Aviation Data Engineering Project

## Overview
End-to-end data engineering pipeline built on Databricks using PySpark.

## Architecture
- Bronze: Streaming ingestion from DBFS
- Silver: Data cleaning & standardization
- Gold: KPI aggregations (monthly, quarterly)
- Dashboard: Matplotlib-based analytics

## Tech Stack
- Databricks
- PySpark
- Delta Lake
- DBFS
- Matplotlib
- GitHub
